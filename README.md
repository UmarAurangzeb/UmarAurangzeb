## About Me

Hey, I'm Umar — a Software Engineer who loves turning ideas into real, shipped products. I work across the full stack with a soft spot for applied AI, building things like RAG pipelines, agentic workflows, and real-time platforms.

Right now I'm shipping production products at **Sliding Scale Technologies**, working end-to-end from idea to deployment. When I'm not building for work, I'm usually exploring new corners of AI engineering or hacking on side projects.

- Currently building full-stack + AI products at **Sliding Scale Technologies**

- Always happy to chat about **Next.js**, **FastAPI**, AI engineering, or system design
